# Bingo Magic Wand (Minecraft 1.21 + Pehkui)

This is a Fabric mod for Minecraft 1.21 that gives every player a magic wand on join. Right-clicking the wand shrinks the player by 0.1, left-clicking grows them by 0.1. The size changes use the Pehkui API.

## Requirements
- Minecraft 1.21
- Fabric Loader
- Fabric API
- Pehkui

## Build
```bash
./gradlew build
```

The built jar will be in `build/libs/`.
